# Features

## content

* [Sutra List](sutra-list.md) - A signed-in user browses the offline-first list of available sutras.
* [Sutra Detail](sutra-detail.md) - A signed-in user reads the full text of one sutra, optionally with chanting audio.
* [Mantra List](mantra-list.md) - A signed-in user browses the offline-first list of available mantras.
* [Mantra Detail](mantra-detail.md) - A signed-in user views the full text of one mantra, optionally with recitation audio.
* [Bodhisattva List](bodhisattva-list.md) - A signed-in user browses the offline-first list of Buddhas and Bodhisattvas.
* [Bodhisattva Detail](bodhisattva-detail.md) - A signed-in user views one Buddha/Bodhisattva's profile and the mantras associated with them.
