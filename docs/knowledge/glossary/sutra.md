A sutra (kinh điển) is a Buddhist scripture users read or chant. It has a
title, a full text body, an optional [sect](/glossary/sect.md), and an
optional chanting audio URL.

Used in [Sutra List](/features/sutra-list.md) and
[Sutra Detail](/features/sutra-detail.md).
